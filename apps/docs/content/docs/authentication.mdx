## Get a key

Create a key from the [console](https://console.hyphenmoney.com). Keys are
scoped to one organization. Propeller will only ever show the full key once —
copy it out and store it in a secrets manager.

<Callout title="Key prefixes.">
  Sandbox keys start with `prop_sk_sandbox_`. Production keys start with
  `prop_sk_live_`. Always use the sandbox key while integrating.
</Callout>

## Make a request

Set `PROPELLER_KEY` in your environment and call any endpoint with the bearer
header.

<CodeBlock snippets={[
  {
    lang: "curl",
    code: `curl https://api.hyphenmoney.com/v1/businesses \\
  -H "Authorization: Bearer $PROPELLER_KEY" \\
  -H "Content-Type: application/json"`,
  },
  {
    lang: "python",
    code: `import os, requests

resp = requests.get(
    "https://api.hyphenmoney.com/v1/businesses",
    headers={"Authorization": f"Bearer {os.environ['PROPELLER_KEY']}"},
)
print(resp.json())`,
  },
  {
    lang: "node",
    code: `const resp = await fetch("https://api.hyphenmoney.com/v1/businesses", {
  headers: {
    Authorization: \`Bearer \${process.env.PROPELLER_KEY}\`,
  },
}).then(r => r.json());
console.log(resp);`,
  },
]} />

## Rotating keys

You can have up to 5 active keys per organization. To rotate:

1. Create a new key in the console.
2. Deploy your app with the new key alongside the old one.
3. Verify traffic is flowing through the new key.
4. Revoke the old key in the console.

Revoked keys stop working immediately. There's no grace period.
