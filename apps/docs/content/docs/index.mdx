## What is Propeller?

Propeller is a regulated **payment corridor** between China and Africa.
Nigerian businesses pay invoices in Naira via bank transfer. Propeller
collects the NGN, runs compliance (KYC, KYB, sanctions screening),
executes the FX, and settles USDC to your destination wallet or exchange.

Propeller acts as **Merchant of Record (MOR)** — the legal counterparty
to both sides of the transaction. You get a clean API: create a business,
issue an invoice, and let Propeller handle the rest.

## Quickstart

Get a sandbox API key from the [console](https://console.withpropeller.com),
set `PROPELLER_KEY`, and create your first business:

<CodeBlock snippets={[
  {
    lang: "curl",
    code: `curl https://api.withpropeller.com/v1/businesses \\
  -H "Authorization: Bearer $PROPELLER_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{
    "name": "Acme Exports Ltd",
    "country": "CN",
    "settlement_address": "0x..."
  }'`,
  },
  {
    lang: "python",
    code: `import requests

resp = requests.post(
    "https://api.withpropeller.com/v1/businesses",
    headers={"Authorization": f"Bearer {PROPELLER_KEY}"},
    json={
        "name": "Acme Exports Ltd",
        "country": "CN",
        "settlement_address": "0x...",
    },
)
print(resp.json())`,
  },
  {
    lang: "node",
    code: `const resp = await fetch("https://api.withpropeller.com/v1/businesses", {
  method: "POST",
  headers: {
    Authorization: \`Bearer \${process.env.PROPELLER_KEY}\`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Acme Exports Ltd",
    country: "CN",
    settlement_address: "0x...",
  }),
});
console.log(await resp.json());`,
  },
]} />
