## Get an API key

Create an account at [console.withpropeller.com](https://console.withpropeller.com).
Sandbox keys are available immediately with no KYC required — enough to explore
the full API surface against test data.

Once you're in the console: **Settings → API keys → New key**. Copy the key
once — Propeller only shows it the one time.

<Callout title="Heads-up.">
  Propeller sandbox keys start with `prop_sk_sandbox_`. Production keys start
  with `prop_sk_live_`.
</Callout>

## Export your key

```bash
export PROPELLER_KEY="prop_sk_sandbox_..."
```

## Make a request

<CodeBlock snippets={[
  {
    lang: "curl",
    code: `curl https://api.withpropeller.com/v1/businesses \\
  -H "Authorization: Bearer $PROPELLER_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{
    "name": "Acme Exports Ltd",
    "country": "CN",
    "settlement_address": "0x..."
  }'`,
  },
  {
    lang: "python",
    code: `import os, requests

resp = requests.post(
    "https://api.withpropeller.com/v1/businesses",
    headers={"Authorization": f"Bearer {os.environ['PROPELLER_KEY']}"},
    json={
        "name": "Acme Exports Ltd",
        "country": "CN",
        "settlement_address": "0x...",
    },
).json()
print(resp["id"], resp["status"])`,
  },
  {
    lang: "node",
    code: `const resp = await fetch("https://api.withpropeller.com/v1/businesses", {
  method: "POST",
  headers: {
    Authorization: \`Bearer \${process.env.PROPELLER_KEY}\`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Acme Exports Ltd",
    country: "CN",
    settlement_address: "0x...",
  }),
}).then(r => r.json());
console.log(resp.id, resp.status);`,
  },
]} />

You should see a JSON response with the business `id` and `status` (likely
`"pending"` while KYB runs). That's it — you've created your first Propeller
resource.
