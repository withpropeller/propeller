## List payouts

`GET /v1/payouts?business_id=biz_01J...&status=settled`

Returns paginated list of payouts.

```json
{
  "data": [
    {
      "id": "pay_01J...",
      "business_id": "biz_01J...",
      "amount_ngn": 1500000,
      "amount_usdc": 947.16,
      "rate": 1583.45,
      "status": "settled",
      "tx_hash": "0xabc123...",
      "settlement_address": "0x742d...",
      "created_at": "2026-05-14T17:30:00Z"
    }
  ]
}
```

## Retrieve a payout

`GET /v1/payouts/{id}`

Returns full payout details including aggregated source payment IDs,
FX rate used, and on-chain transaction reference.
